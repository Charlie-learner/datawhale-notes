## 目录约定

每门课程使用一个独立文件夹，课程文件夹内按照 `taskNN-主题.md` 命名：

```text
datawhale-notes/
├── README.md
└── deepagents-in-action/
    ├── README.md
    ├── task01-environment-setup.md
    ├── task02-first-deep-agent.md
    └── code/
        └── task02/
            └── hello_weather.py
```

## 内容原则

- 记录真实执行过程和可复现命令；
- 区分成功结果、失败现象和推测；
- 不提交 API Key、密码、`.env` 或含敏感信息的 Trace；
- 截图上传前检查账号、路径、Token 和个人信息；
- 引用教程或官方资料时保留原始链接。
